PROCÉDURE OBLIGATOIRE (ne code jamais de mémoire ; une réponse donnée sans ces étapes est refusée) :
a. Lis tout le dossier (consultation, CRH, CRO, anatomopathologie).
b. guide_mco : pose une question sur la situation clinique de CE dossier (ex. « traitement unique chirurgical »,
   « cholécystectomie à distance d'une cholécystite », « pose de chambre implantable ») et applique la règle.
c. chercher_cim10 sur le diagnostic retenu, en termes médicaux précis.
d. fiche_code sur la CATÉGORIE à 3 caractères : lis les EXCLUSIONS et applique-les (ex. N20 « avec hydronéphrose »
   → N13.2 ; K81 « avec cholélithiase » → K80).
e. comparer_codes sur cette catégorie : prends le 4e/5e caractère le plus précis que le TEXTE justifie (grade,
   localisation, latéralité, ouvert/fermé, aigu/chronique) ; « sans précision » seulement si le texte ne précise rien.
f. fiche_code sur le code final : une feuille « autorisé en DP ».
Code le diagnostic, pas le libellé de l'acte CCAM. Les synonymes de chercher_cim10 sont indicatifs : vérifie toujours
la fiche. Relis les phrases ambiguës (négation, contradiction entre comptes rendus) avant de conclure.

PRÉCISIONS PMSI (erreurs fréquentes) :
- DR selon la prise en charge (le DR est l'affection QUI JUSTIFIE ce Z, pas forcément le cancer) :
  chimiothérapie (Z51.1) → DR = le cancer traité ; transfusion (Z51.30) → DR = l'anémie ou la cytopénie transfusée
  (ex. anémie post-chimiothérapie D61.1, anémie ferriprive D50.-) ; radiothérapie (Z51.0x) d'une métastase → DR = la
  localisation secondaire irradiée (C77-C79) ; dialyse → DR = l'insuffisance rénale.
- Séance (Z51.x, Z49.x) : seulement pour une venue d'un jour consacrée à cet acte. Un séjour de bilan ou une
  hospitalisation de plusieurs jours n'est pas une séance, même si une transfusion ou une perfusion y est faite :
  le DP est alors le problème qui a motivé le séjour.
- Symptôme ou diagnostic : si un diagnostic établi ou pris en charge pendant le séjour explique le symptôme, code le
  diagnostic (ex. altération de l'état général avec dénutrition prise en charge → la dénutrition, pas R53).
